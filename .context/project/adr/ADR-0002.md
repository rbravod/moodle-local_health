# ADR-0002: Independencia entre probes

## Estado

Propuesta

## Contexto

El modelo de ejecución debe permitir incorporar probes de forma predecible y sin acoplar el núcleo a relaciones específicas entre comprobaciones.

## Propuesta

Cada probe será una unidad de ejecución independiente que responderá a una única pregunta sobre el estado del sistema.

El framework no modelará dependencias ni establecerá un orden de ejecución entre probes. Una probe será responsable de realizar las comprobaciones necesarias para producir su propio resultado.

## Consecuencias

- El agregador recibe resultados independientes.
- Las dependencias técnicas se encapsulan dentro de la probe que las necesita.
- No se añadirá un grafo de dependencias ni un planificador de probes en el núcleo.
