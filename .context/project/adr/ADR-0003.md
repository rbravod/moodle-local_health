# ADR-0003: Descubrimiento de probes mediante atributos PHP

## Estado

En evaluación

## Contexto

El plugin necesita un mecanismo para registrar y descubrir probes. Moodle utiliza atributos PHP en su API de routing, por lo que este mecanismo es una alternativa a evaluar.

## Propuesta en evaluación

Definir una anotación de atributo para declarar los metadatos de una probe y descubrir las clases registradas mediante Reflection.

```php
#[Probe(
    id: 'core.database',
    name: 'Database',
)]
class database_probe {
    // ...
}
```

## Criterios de decisión

- Compatibilidad con Moodle 5.1 a 5.3.
- Facilidad para desarrollar extensiones de terceros.
- Coste y previsibilidad del descubrimiento.
- Claridad del contrato público de una probe.
